## 🚀 快速部署步骤

### 方式一：使用快速启动脚本（推荐）
```bash
# 1. 下载项目包
wget https://your-domain.com/releases/multiplayer-game-project-v1.0.0.zip

# 2. 解压
unzip multiplayer-game-project-v1.0.0.zip
cd multiplayer-game-project

# 3. 运行快速启动脚本
chmod +x quick-start.sh
./quick-start.sh

# 4. 访问游戏
# 服务端: http://localhost:3000
# 客户端: http://localhost:5173
```

### 方式二：手动部署
```bash
# 1. 安装依赖
npm install

# 2. 配置环境
cp .env.example .env
# 编辑配置文件

# 3. 启动服务端
node start-server.js

# 4. 启动客户端（新终端）
node start-client.js
```

### 方式三：Docker部署
```bash
# 1. 构建镜像
docker build -t multiplayer-game:latest .

# 2. 运行容器
docker-compose up -d

# 3. 查看状态
docker-compose ps
```
