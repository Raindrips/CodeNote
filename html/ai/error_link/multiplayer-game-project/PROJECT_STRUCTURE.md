# 多人游戏项目结构说明

本文档详细说明了多人游戏项目的目录结构和文件用途，帮助开发者快速理解项目架构。

## 📁 项目根目录

```
multiplayer-game-project/
├── server/                    # 服务端代码目录
├── client/                    # 客户端代码目录
├── docs/                      # 项目文档目录
├── logs/                      # 日志文件目录
├── scripts/                   # 脚本文件目录
├── config.json               # 项目主配置文件
├── package.json              # Node.js项目配置
├── Dockerfile                # Docker镜像配置
├── docker-compose.yml        # Docker Compose配置
├── deploy.sh                 # 部署脚本
├── start-server.js           # 服务端启动脚本
├── start-client.js           # 客户端启动脚本
├── test-integration.js       # 集成测试脚本
├── .env.example              # 环境变量示例
├── README.md                 # 项目说明文档
└── PROJECT_STRUCTURE.md      # 项目结构说明（本文档）
```

## 🖥️ 服务端目录 (server/)

服务端采用模块化架构，每个模块负责特定的功能。

```
server/
├── index.js                  # 主服务器文件
└── modules/                  # 核心模块目录
    ├── UserManager.js        # 用户管理模块
    ├── MessageHandler.js     # 消息处理模块
    ├── BroadcastManager.js   # 广播管理模块
    ├── GameRoom.js           # 游戏房间模块
    ├── RoomManager.js        # 房间管理模块
    └── SecurityManager.js    # 安全管理模块
```

### 服务端文件详细说明

#### `server/index.js`
- **作用**: 主服务器入口文件
- **功能**: 
  - 创建WebSocket服务器
  - 管理客户端连接
  - 处理连接事件
  - 协调各模块工作

#### `server/modules/UserManager.js`
- **作用**: 用户状态管理
- **功能**:
  - 用户连接状态管理
  - 在线用户列表维护
  - 用户位置信息存储
  - 用户搜索和统计

#### `server/modules/MessageHandler.js`
- **作用**: 消息处理中心
- **功能**:
  - 解析客户端消息
  - 路由消息到相应处理器
  - 消息验证和错误处理
  - 业务逻辑处理

#### `server/modules/BroadcastManager.js`
- **作用**: 消息广播管理
- **功能**:
  - 消息广播机制
  - 批量消息处理
  - 系统消息发送
  - 性能优化（消息合并）

#### `server/modules/GameRoom.js`
- **作用**: 游戏房间管理
- **功能**:
  - 房间创建和管理
  - 玩家加入/离开处理
  - 房间状态管理
  - 房间内广播

#### `server/modules/RoomManager.js`
- **作用**: 多房间系统管理
- **功能**:
  - 多房间支持
  - 房间推荐算法
  - 负载均衡
  - 房间统计

#### `server/modules/SecurityManager.js`
- **作用**: 安全防护
- **功能**:
  - 速率限制
  - 消息过滤
  - 用户封锁
  - 安全检查

客户端采用现代Web技术，提供流畅的游戏体验。

```
client/
```

#### `client/scripts/`

## 📋 配置和脚本文件

### 配置文件

#### `config.json`
- **作用**: 项目主配置文件
- **内容**:
  - 服务端配置（端口、主机、最大用户数）
  - 客户端配置（Canvas设置、玩家设置）
  - 游戏配置（世界边界、物理参数）
  - 消息协议定义

#### `.env.example`
- **作用**: 环境变量配置示例
- **内容**:
  - 基础环境配置
  - 数据库连接配置
  - 第三方服务配置
  - 安全配置

### 启动和部署脚本

#### `start-server.js`
- **作用**: 服务端启动脚本
- **功能**:
  - 环境检查
  - 依赖验证
  - 端口检查
  - 服务启动
  - 日志输出

#### `start-client.js`
- **作用**: 客户端启动脚本
- **功能**:
  - 开发服务器启动
  - 构建工具调用
  - 浏览器自动打开
  - 静态文件服务

#### `deploy.sh`
- **作用**: 项目部署脚本
- **功能**:
  - 多种部署方式（本地、Docker、PM2、远程）
  - 环境配置
  - 服务管理
  - 健康检查

#### `test-integration.js`
- **作用**: 集成测试脚本
- **功能**:
  - WebSocket连接测试
  - 用户登录测试
  - 玩家移动测试
  - 多玩家场景测试
  - HTTP服务测试

### Docker相关文件

#### `Dockerfile`
- **作用**: Docker镜像构建配置
- **功能**:
  - 基础镜像选择
  - 依赖安装
  - 文件复制
  - 权限设置
  - 健康检查

#### `docker-compose.yml`
- **作用**: Docker Compose服务编排
- **功能**:
  - 多服务定义
  - 网络配置
  - 卷挂载
  - 环境变量
  - 依赖关系

#### `docker-entrypoint.sh`
- **作用**: Docker容器入口脚本
- **功能**:
  - 环境初始化
  - 配置检查
  - 服务启动
  - 信号处理
