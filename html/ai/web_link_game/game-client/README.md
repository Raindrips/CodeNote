# 多人在线游戏客户端

这是一个使用原生JavaScript开发的多人在线游戏客户端，支持WebSocket实时通信和Canvas渲染。

## 功能特性

### 🎮 核心功能
- **实时多人游戏**: 通过WebSocket连接服务端，支持多玩家同时在线
- **Canvas渲染**: 使用HTML5 Canvas进行游戏画面渲染
- **角色系统**: 玩家由emoji头像和文字名称组成
- **键盘控制**: 支持方向键控制角色移动
- **实时同步**: 玩家位置和状态实时同步

### 🎯 控制方式
- **键盘控制**: 使用方向键（↑↓←→）控制角色移动
- **触摸控制**: 移动设备支持虚拟摇杆控制
- **鼠标控制**: 支持鼠标拖拽控制
- **快捷键**:
  - `Ctrl+C`: 连接/断开服务器
  - `Ctrl+R`: 重新连接
  - `F11`: 全屏模式

### 🌐 网络功能
- **WebSocket连接**: 实时双向通信
- **自动重连**: 连接断开时自动尝试重连
- **消息队列**: 离线时消息缓存，连接后自动发送
- **状态同步**: 玩家加入、离开、位置更新实时同步

### 🎨 界面特性
- **响应式设计**: 适配桌面和移动设备
- **现代UI**: 毛玻璃效果、渐变背景、动画效果
- **实时反馈**: 连接状态、玩家数量、游戏日志
- **虚拟摇杆**: 移动设备专用控制界面

## 快速开始

### 1. 启动游戏服务器
确保游戏服务器已运行（参考game-server目录）

### 2. 打开客户端
在浏览器中打开 `index.html` 文件

### 3. 连接服务器
1. 输入玩家名称
2. 输入服务器地址（默认: ws://localhost:8080）
3. 点击"连接服务器"按钮

### 4. 开始游戏
使用方向键控制角色在地图上移动

## 配置说明

### 服务器配置
- 默认服务器地址: `ws://localhost:8080`
- 支持自定义服务器地址

### 游戏设置
- 玩家名称: 最大长度10个字符
- 移动速度: 通过网络同步，服务端控制
- 世界大小: 2000x2000像素

## 技术细节

### 渲染系统
- **坐标系统**: 世界坐标系和屏幕坐标系转换
- **相机跟随**: 本地玩家始终在屏幕中央
- **性能优化**: 只渲染可见区域内的玩家

### 网络协议
消息格式:
```javascript
{
    type: 'join' | 'move' | 'stopMove' | 'playerUpdate',
    playerId?: string,
    playerName?: string,
    x?: number,
    y?: number,
    direction?: string
}
```

### 移动控制
- **键盘**: 方向键组合实现8方向移动
- **触摸**: 角度计算转换为方向
- **鼠标**: 拖拽距离和角度控制
- **虚拟摇杆**: 模拟物理摇杆操作

## 开发指南

### 调试模式
在浏览器控制台中可以使用以下调试命令：

```javascript
// 重启游戏
gameDebug.restart()

// 暂停游戏
gameDebug.pause()

// 恢复游戏
gameDebug.resume()

// 获取网络模块
gameDebug.getNetwork()

// 获取渲染器
gameDebug.getRenderer()

// 获取控制器
gameDebug.getControls()
```

### 自定义扩展
1. **添加新角色**: 修改 `game-renderer.js` 中的 `playerEmojis` 数组
2. **调整移动速度**: 修改 `game-controls.js` 中的 `moveSpeed` 值
3. **自定义样式**: 修改 `styles.css` 文件

### 性能优化
- 使用 `requestAnimationFrame` 进行游戏循环
- 限制消息发送频率（50ms间隔）
- 只渲染可见区域内的对象
- 使用对象池减少垃圾回收

## 故障排除

### 连接失败
1. 检查服务器是否运行
2. 确认服务器地址是否正确
3. 检查防火墙设置
4. 查看浏览器控制台错误信息

### 控制无响应
1. 确认游戏窗口获得焦点
2. 检查是否有其他程序占用方向键
3. 尝试重新连接服务器

### 渲染问题
1. 确认浏览器支持Canvas
2. 检查是否有浏览器插件冲突
3. 尝试刷新页面
