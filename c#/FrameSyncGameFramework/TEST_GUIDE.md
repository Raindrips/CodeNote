# FrameSync Game Framework 测试指南

## 概述

本文档提供了FrameSync游戏框架的详细测试说明，包括功能测试、性能测试和集成测试步骤。

## 环境准备

### 系统要求
- .NET 6.0 SDK 或更高版本
- 至少 2GB 可用内存
- 100MB 可用磁盘空间

### 安装依赖
```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install dotnet-sdk-6.0

# Windows
# 从 https://dotnet.microsoft.com/download 下载并安装

# macOS
brew install dotnet
```

## 编译项目

### 使用构建脚本
```bash
chmod +x build.sh
./build.sh
```

### 手动编译
```bash
dotnet restore
dotnet build --configuration Release
```

## 故障排除

### 常见问题

#### 编译失败
**问题**: dotnet命令未找到
**解决**: 确保.NET SDK正确安装并配置PATH

#### 运行时错误
**问题**: 程序崩溃或异常
**解决**: 
1. 检查日志输出
2. 验证依赖项
3. 检查文件权限

#### 网络连接失败
**问题**: 无法建立网络连接
**解决**:
1. 检查防火墙设置
2. 验证端口是否开放
3. 检查网络配置

#### 性能问题
**问题**: 帧率过低或卡顿
**解决**:
1. 降低帧率设置
2. 优化序列化频率
3. 检查内存使用

### 调试技巧

#### 启用详细日志
```csharp
// 在Program.cs中修改日志级别
services.AddLogging(builder =>
{
    builder.AddConsole()
           .SetMinimumLevel(LogLevel.Debug); // 改为Debug级别
});
```

#### 性能分析
```bash
# 使用dotnet-counters监控性能
dotnet-counters monitor --process-id <PID>

# 使用dotnet-trace记录性能数据
dotnet-trace collect --process-id <PID>
```

#### 内存分析
```bash
# 使用dotnet-dump分析内存
dotnet-dump collect --process-id <PID>
dotnet-dump analyze <dump-file>
```
